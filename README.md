# quantum-computing-for-developers-ja

開発者のための量子コンピューティング実践入門

- `docs/`：元記事を保持する初期資料
- `manuscript/`：書籍として再構成した原稿とPDF生成ツール
- `examples/`：環境定義を含む、単独実行可能な検証済みコード例

コード例の環境準備と一括実行は [examples/README.md](examples/README.md) を参照してください。

章別の確認用出典は `manuscript/book.json`、書誌情報は `manuscript/editorial/sources.json` と `manuscript/backmatter/references.md`、用語集は `manuscript/backmatter/glossary.md` で管理します。対応関係は `python manuscript/tools/audit_references.py` で検証できます。

# 1. 固有値問題とは何か？

まず：

VQEが解いている問題

を理解しましょう。

対象は：

```text
H |ψ⟩ = E |ψ⟩
```

です。

これは：

ハミルトニアン H の固有値問題

です。

意味：

* |ψ⟩ = 状態
* E = エネルギー

つまり：

> 最小エネルギー状態を見つける問題

です。

これは量子化学で重要です。

なぜなら：

分子の性質は

**基底状態エネルギー**

で決まるからです。

---

# 2. なぜ量子化学が最初の応用なのか？

例えば：

水分子 H₂O

の電子状態を計算したいとします。

古典計算では：

電子数 n に対して

計算量：

```text
O(2^n)
```

になります。

つまり：

すぐ爆発します。

しかし量子コンピュータでは：

電子も量子状態

なので：

自然に表現できます。

つまり：

量子化学は

量子コンピュータにとって

最も自然な問題

なのです。

---

# 3. しかしShorのようなアルゴリズムは使えない

理想的には：

量子位相推定（QPE）

を使えば

固有値は正確に求まります。

しかし：

QPEは

* 深い回路が必要
* 多くの量子ビットが必要
* 誤り訂正が必要

です。

つまり：

NISQでは動きません。

そこで登場するのが：

VQEです。

---

# 4. VQEの基本アイデア

VQEの考え方は驚くほどシンプルです：

① 仮の状態を作る
② エネルギーを測る
③ パラメータを調整する
④ 最小になるまで繰り返す

つまり：

機械学習と似ています。

構造：

```
量子回路 → 測定 → 古典最適化 → 更新
```

です。

---

# 5. 変分原理とは何か？

VQEの数学的基盤は：

変分原理です。

内容：

任意の状態 |ψ⟩ に対して

```
⟨ψ|H|ψ⟩ ≥ E₀
```

が成立します。

ここで：

E₀ = 真の基底状態エネルギー

つまり：

> エネルギーを最小化すれば基底状態に近づく

ということです。

これが：

VQEの核心です。

---

# 6. パラメータ付き量子回路とは何か？

通常の量子回路：

```
H
CNOT
X
```

固定です。

VQEでは：

```
Ry(θ)
Rz(θ)
```

のように：

パラメータ θ を持つゲート

を使います。

例：

```
|0⟩ → Ry(θ) |0⟩
```

θ を変えると：

状態が変わります。

つまり：

量子状態を連続的に探索できます。

---

# 7. VQEの処理フロー

VQEは次のループです：

① 初期パラメータ θ を選ぶ
② 回路を実行
③ エネルギーを測定
④ 古典最適化
⑤ θ を更新

図式：

```
θ → 量子回路 → 測定 → E
↑                   ↓
└──── 古典最適化 ───┘
```

これを：

収束するまで繰り返します。

---

# 8. なぜハイブリッドになるのか？

理由は明確です：

量子回路は：

期待値計算が得意

古典計算は：

最適化が得意

つまり：

役割分担します。

```
量子：状態生成
古典：パラメータ更新
```

これが：

NISQアルゴリズムの基本設計です。

---

# 9. ハミルトニアンはどう測定するのか？

重要なポイント：

H は通常：

複数の項の和

として書かれます。

例：

```
H = Z₀Z₁ + X₀X₁ + Z₀
```

すると：

期待値は：

```
⟨H⟩ =
⟨Z₀Z₁⟩ +
⟨X₀X₁⟩ +
⟨Z₀⟩
```

として計算できます。

つまり：

複数回測定して

足し合わせます。

---

# 10. Qiskitで最小VQEを書く

最小例：

2量子ビット回路

```python
from qiskit import QuantumCircuit
from numpy import pi

qc = QuantumCircuit(2)

qc.ry(pi/4, 0)
qc.ry(pi/3, 1)
qc.cx(0, 1)

qc.draw("text")
```

ここで：

```
pi/4
pi/3
```

が

最適化対象パラメータ

になります。

実際のVQEでは：

これをループさせます。

---

# 11. Ansatz（アンザッツ）とは何か？

VQEで最重要概念：

**Ansatz**

意味：

仮定する状態の形

例：

```
Ry
Rz
CNOT
Ry
```

のような回路構造です。

良いAnsatzとは：

* 表現力が高い
* 回路が浅い
* ノイズに強い

ものです。

VQEの性能は：

Ansatzで決まります。

---

# 12. VQEが実用に近い理由

VQEは：

NISQ向きです。

理由：

① 回路が浅い
② 量子ビットが少ない
③ ノイズに比較的強い
④ ハイブリッド構造

そのため：

実機で動く量子アルゴリズム

として最初に研究されました。

応用例：

* 分子エネルギー推定
* 材料設計
* 触媒設計
* 創薬

です。

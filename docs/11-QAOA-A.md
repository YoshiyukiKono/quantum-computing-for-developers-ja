---

# 1. 組合せ最適化とは何か？

組合せ最適化とは：

> 多数の候補の中から最も良い組合せを選ぶ問題

です。

代表例：

* 配送ルート最適化（TSP）
* スケジューリング
* 配線最適化
* ポートフォリオ最適化
* Max-Cut問題

特徴は：

候補数が指数関数的に増える

ことです。

例えば：

N個のビットなら

```
2^N 通り
```

の候補があります。

50ビットなら：

```
約 10^15 通り
```

総当たり探索は現実的ではありません。

ここで登場するのが：

量子干渉による探索の偏り

という考え方です。

---

# 2. QAOAとは何か？

QAOAとは：

> 最適解に近い解の確率を干渉によって増幅するアルゴリズム

です。

特徴：

| 項目      | 内容             |
| ------- | -------------- |
| ハイブリッド型 | 量子＋古典の協調計算     |
| NISQ向け  | 現在の量子デバイスで実行可能 |
| 汎用性     | 多くの最適化問題に適用可能  |

基本構造は：

```
初期状態
↓
コストハミルトニアン
↓
ミキサーハミルトニアン
↓
繰り返し
↓
測定
```

です。

---

# 3. Max-Cut問題とは何か？

QAOAの最も基本的な対象問題が：

**Max-Cut問題**

です。

問題：

グラフの頂点を2グループに分けて

グループ間を跨ぐ辺の数を最大化する

例：

```
A --- B
|     |
C --- D
```

このとき：

```
{A, D}
{B, C}
```

のように分割すると、

多くの辺がグループ間を跨ぎます。

これが良い解です。

---

# 4. なぜMax-Cutは量子化できるのか？

各頂点を：

```
|0⟩
|1⟩
```

で表します。

例えば：

```
|0⟩ → グループA
|1⟩ → グループB
```

すると問題は：

どのビット列が最適か？

という形に変換できます。

例：

```
|0101⟩
```

これは：

頂点の分割方法

を意味します。

---

# 5. コストハミルトニアンとは何か？

QAOAの中心となるのが：

**コストハミルトニアン**

です。

これは：

> 解の良さをエネルギーとして表現したもの

です。

考え方：

良い解ほど低エネルギー

になるように設計します。

つまり：

```
最適解 = 基底状態
```

になります。

---

# 6. Max-Cutのコストハミルトニアン

Max-Cutでは：

異なるグループに属する頂点の数

を最大化します。

そのため：

* 同じグループ → ペナルティ
* 異なるグループ → 報酬

という構造のハミルトニアンを作ります。

すると：

問題は

```
最低エネルギー状態を探す問題
```

に変換されます。

これは：

量子コンピュータが得意な形式

です。

---

# 7. ミキサーハミルトニアンとは何か？

コストハミルトニアンだけでは：

探索が止まります。

理由：

状態が固定されてしまうからです。

そこで導入するのが：

**ミキサーハミルトニアン**

です。

役割：

```
状態を探索空間全体に広げる
```

つまり：

| ハミルトニアン | 役割        |
| ------- | --------- |
| コスト     | 最適解へ引き寄せる |
| ミキサー    | 探索範囲を広げる  |

になります。

---

# 8. QAOAの基本アルゴリズム

QAOAは次の操作を繰り返します：

```
① 初期状態生成
② コストハミルトニアン作用
③ ミキサーハミルトニアン作用
④ パラメータ更新
⑤ 繰り返し
```

ここで重要なのが：

```
γ（ガンマ）
β（ベータ）
```

というパラメータです。

これらが：

干渉の仕方

を決めます。

---

# 9. なぜパラメータ最適化が必要なのか？

QAOAでは：

```
γ
β
```

を調整することで

解の確率分布が変わります。

つまり：

```
干渉パターンを最適化する
```

という問題になります。

流れ：

```
量子回路実行
↓
測定
↓
評価
↓
パラメータ更新
↓
再実行
```

量子と古典の協調アルゴリズムです。

# 10. VQEとの違い

ここまで読むと：

VQEと似ている

と感じるはずです。

違いを整理すると：

| 項目      | VQE    | QAOA  |
| ------- | ------ | ----- |
| 目的      | 基底状態探索 | 最適化問題 |
| 対象      | 物理系    | 組合せ問題 |
| 回路      | 任意設計   | 構造固定  |
| ハミルトニアン | 自然現象   | 問題定義  |

つまり：

VQE：

自然の最低エネルギー状態を探す

QAOA：

問題の最適解を探す

です。

などです。

# 1. 組合せ最適化とは何か？

組合せ最適化とは：

> 多数の選択肢の組合せの中から最も良いものを選ぶ問題

です。

代表例：

* 配送ルート最適化（TSP）
* スケジューリング
* ポートフォリオ最適化
* 回路配置
* クラスタリング
* Max-Cut問題

特徴：

探索空間が指数関数的に増える

例：

Nビットなら

```
2^N 通り
```

つまり：

20ビット → 約100万通り
50ビット → 約10^15通り

総当たりは不可能になります。

ここに量子アルゴリズムが登場します。

---

# 2. QAOAとは何か？

QAOAとは：

> 最適解に近い解を量子干渉で強調するアルゴリズム

です。

特徴：

| 特徴     | 内容               |
| ------ | ---------------- |
| NISQ向け | 現在の量子ハードウェアで実行可能 |
| 変分型    | パラメータ最適化を含む      |
| 実用志向   | 現実問題への応用が期待される   |

構造は非常にシンプル：

```
初期状態
↓
コストハミルトニアン
↓
ミキサーハミルトニアン
↓
繰り返し
↓
測定
```

---

# 3. Max-Cut問題とは何か？

QAOAの最も有名な例が：

**Max-Cut問題**

です。

問題：

グラフの頂点を2グループに分ける
辺がグループ間を跨ぐ数を最大化する

例：

```
A --- B
|     |
C --- D
```

分割：

```
{A, D}
{B, C}
```

このとき：

跨いでいる辺が最大なら最適解

---

# 4. なぜMax-Cutは量子化できるのか？

各頂点を：

```
0 or 1
```

で表します。

つまり：

```
|0⟩ → グループA
|1⟩ → グループB
```

に対応させる。

すると：

問題は

```
どのビット列が最適か？
```

に変換できます。

ここで登場するのが：

**コストハミルトニアン**

です。

---

# 5. コストハミルトニアンとは何か？

コストハミルトニアンとは：

> 解の良さをエネルギーとして表現したもの

です。

最適化問題では：

良い解ほどエネルギーが低い

ように設計します。

つまり：

```
最適解 = 基底状態
```

になります。

Max-Cutでは：

異なるグループに属する頂点の数

を最大化したい。

そのため：

```
同じグループ → ペナルティ
違うグループ → 報酬
```

という形のハミルトニアンを作ります。

---

# 6. コストハミルトニアンの直感

イメージ：

```
悪い解 → 高エネルギー
普通の解 → 中エネルギー
良い解 → 低エネルギー
最適解 → 最低エネルギー
```

QAOAは：

最低エネルギー状態を探す

アルゴリズムです。

---

# 7. ミキサーハミルトニアンとは何か？

コストハミルトニアンだけでは：

探索が止まってしまう

問題があります。

そこで必要なのが：

**ミキサーハミルトニアン**

です。

役割：

```
状態を探索空間全体に広げる
```

つまり：

```
探索の自由度を与える
```

働きをします。

直感：

| ハミルトニアン | 役割        |
| ------- | --------- |
| コスト     | 最適解へ引き寄せる |
| ミキサー    | 探索範囲を広げる  |

---

# 8. QAOAの基本構造

QAOAは次の操作を繰り返します：

```
① 初期状態生成
② コスト作用
③ ミキサー作用
④ 繰り返し
⑤ 測定
```

式で書くと：

```
U(C,γ) → U(B,β)
```

を交互に適用します。

ここで：

| 記号 | 意味          |
| -- | ----------- |
| C  | コストハミルトニアン  |
| B  | ミキサーハミルトニアン |
| γ  | コスト角度       |
| β  | ミキサー角度      |

---

流れ：

```
量子回路実行

```

量子＋古典のハイブリッドアルゴリズムです。

# 10. VQEとの違い

ここで疑問が出ます：

QAOAとVQEは何が違うのか？

整理すると：

| 項目      | VQE    | QAOA  |
| ------- | ------ | ----- |
| 目的      | 基底状態探索 | 最適化問題 |
| 対象      | 物理系    | 組合せ問題 |
| 回路      | 任意設計   | 構造固定  |
| ハミルトニアン | 物理モデル  | 問題モデル |

つまり：

VQE：

```
自然のエネルギー最小化
```

QAOA：

```
問題の最適解探索
```

です。

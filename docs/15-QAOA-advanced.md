# 1. p層QAOAとは何か？

これまで扱ってきた回路は：

p = 1

でした。

一般形のQAOAは：

$$
U(\vec{\beta}, \vec{\gamma}) = \prod_{k=1}^{p} e^{-i \beta_k H_B} e^{-i \gamma_k H_C}
$$

つまり：

```text
Cost → Mixer
Cost → Mixer
Cost → Mixer
...
```

をp回繰り返します。

---

# 2. なぜpを増やすと性能が上がるのか？

理由：

干渉の自由度が増えるから

です。

直感：

| p | 探索能力         |
| - | ------------ |
| 1 | 粗い探索         |
| 2 | 局所改善         |
| 3 | 高精度探索        |
| 大 | 量子アニーリングに近づく |

理論的には：

p → ∞

で最適解に収束可能と知られています。

ただし現実では：

```text
回路が深くなる = ノイズ増加
```

という制約があります。

---

# 3. p層QAOAの実装方法

p層化は単純です：

```python
for layer in range(p):

    apply_cost_unitary(qc, gamma[layer], graph)
    apply_mixer_unitary(qc, beta[layer], n)
```

パラメータ数：

```text
2p個
```

になります。

例：

| p  | パラメータ数 |
| -- | ------ |
| 1  | 2      |
| 2  | 4      |
| 5  | 10     |
| 10 | 20     |

---

# 4. warm-start QAOAとは何か？

通常のQAOAは：

均等重ね合わせ状態

から開始します：

```text
|+⟩⊗n
```

しかし実問題では：

古典アルゴリズムで

ある程度良い解

が得られる場合があります。

そこで：

その解を初期状態として使う

のが：

**warm-start QAOA**

です。

---

# 5. warm-startのメリット

通常の初期状態：

```text
全探索
```

warm-start：

```text
有望領域のみ探索
```

つまり：

| 方法         | 特徴   |
| ---------- | ---- |
| 通常QAOA     | 広く探索 |
| warm-start | 深く探索 |

になります。

---

# 6. warm-startの実装方法

例えば：

古典解：

```text
010110
```

が得られている場合：

初期状態を：

```python
if bit == 1:
    qc.x(i)
```

で準備できます。

さらに一般化すると：

回転角として与える方法：

```python
qc.ry(theta[i], i)
```

です。

これにより：

確率分布付き初期状態

が作れます。

---

# 7. 制約付き最適化問題とは何か？

現実問題では：

自由なビット列

が許されない場合があります。

例：

* ポートフォリオ選択（投資数固定）
* スケジューリング（同時実行禁止）
* 配置問題（資源制約）
* ルーティング（経路制約）

通常のQAOAでは：

```text
すべてのビット列が探索対象
```

になります。

しかし必要なのは：

```text
制約を満たす状態のみ探索
```

です。

---

# 8. 制約付きMixerとは何か？

通常のMixer：

$$
H_B = \sum_i X_i
$$


これは：

全状態を自由に移動します。

制約付きMixerでは：

制約を破らない遷移のみ

許可します。

例：

```text
ビット数固定
```

なら：

```text
01 ↔ 10 はOK
00 ↔ 11 はNG
```

のような遷移になります。

---

# 9. Mixer設計が重要な理由

QAOAの性能は：

実は

Mixer設計

に強く依存します。

理由：

```text
探索可能な空間を決めるから
```

です。

整理すると：

| Mixer     | 探索範囲    |
| --------- | ------- |
| 標準Mixer   | 全空間     |
| 制約Mixer   | 制約空間のみ  |
| 問題特化Mixer | 最適化効率向上 |

---

# 10. 問題特化Mixerの例

代表例：

XY Mixer

形式：

```text
X_i X_j + Y_i Y_j
```

用途：

```text
ビット数保存制約
```

に対応できます。

これは：

量子ウォーク型探索

として理解できます。

# 1. 量子アニーリングとは何か？

量子アニーリングとは：

> 最適解を基底状態として持つハミルトニアンへゆっくり変形することで解を得る方法

です。

直感：

```text
簡単な問題
↓
少し難しい問題
↓
本当の問題
```

と連続的に変化させることで：

基底状態を追跡する

という考え方です。

---

# 2. なぜ基底状態が重要なのか？

組合せ最適化問題は：

次の形に変換できます：

```text
最適解 = 最低エネルギー状態
```

つまり：

問題をハミルトニアンとして表現する

ことが核心になります。

---

# 3. Isingモデルとは何か？

量子最適化問題の多くは： **Isingモデル** として書けます。

代表的な形：


H = \sum_i h_i Z_i + \sum_{i<j} J_{ij} Z_i Z_j


ここで：

| 記号       | 意味     |
| -------- | ------ |
| (Z_i)    | スピン状態  |
| (h_i)    | 局所バイアス |
| (J_{ij}) | 相互作用   |

例えば：

* Max-Cut
* ポートフォリオ最適化
* スケジューリング
* SAT問題

などがこの形式になります。

つまり：

**Ising形式に変換できれば量子最適化できる**

ということです。

---

# 4. 断熱量子計算（Adiabatic Quantum Computing）

量子アニーリングの理論的基盤は：

断熱量子計算

です。

基本式：

```text
H(t) = (1 − s(t)) H_B + s(t) H_C
```

意味：

| ハミルトニアン | 役割     |
| ------- | ------ |
| (H_B)   | 初期状態生成 |
| (H_C)   | 解を持つ問題 |

時間とともに：

```text
H_B → H_C
```

へ変形します。

もし変化が十分ゆっくりなら：

基底状態は保たれます。

これが：

断熱定理

です。

---

# 5. 量子アニーリングの流れ

処理の流れ：

```text
① 初期基底状態を準備
② ハミルトニアンをゆっくり変形
③ 最終基底状態を測定
```

結果：

最適解が得られます。

---

# 6. QAOAとの関係

ここで重要なポイント：

QAOAは

**断熱量子計算の離散化**

として理解できます。

断熱計算：

```text
連続変化
```

QAOA：

```text
段階変化
```

対応関係：

| 断熱量子計算 | QAOA   |
| ------ | ------ |
| 時間発展   | 層構造    |
| 連続変形   | 離散ステップ |
| 長時間進化  | 小さなp   |

つまり：

```text
p → ∞
```

で：

QAOA ≒ 断熱量子計算

になります。

---

# 7. 数式で見る対応関係

断熱計算：

```text
exp(−i ∫ H(t) dt)
```

QAOA：

```text
exp(−i β H_B) exp(−i γ H_C)
```

これを：

交互に適用します。

つまり：

時間発展を分割したもの

がQAOAです。

---

# 8. なぜQAOAが重要なのか？

断熱計算を直接実装できない

代わりに：

ゲート型量子コンピュータ

が主流です。

そこで：

断熱計算をゲート化した

QAOAが登場しました。

# 9. ゲート型 vs アニーリング型量子コンピュータ

量子最適化には：

2種類のハードウェアがあります。

比較：

| 項目     | ゲート型         | アニーリング型 |
| ------ | ------------ | ------- |
| 代表     | IBM / Google | D-Wave  |
| アルゴリズム | QAOA         | QA      |
| 汎用性    | 高い           | 低い      |
| 最適化性能  | 研究段階         | 実務利用あり  |
| 回路設計   | 必要           | 不要      |

つまり：

```text
アニーリング型 = 専用機
ゲート型 = 汎用機
```

です。

# コラム：　Isingモデルとは何か？

## ― なぜその名前なのか？量子計算にもつながる「最も有名な磁石モデル」入門 ―

量子コンピュータやQAOA、組合せ最適化を勉強していると、突然現れる言葉があります。

最初は、

……何の話をしているのか分からなくなります。

しかし実は、Isingモデルはかなりシンプルです。

本質的には：

> 「隣同士が仲良くしたがる世界」

を数式化したものです。

そして驚くほど多くの問題が、この形に変換できます。

---

# なぜ「Ising（イジング）」という名前？

名前の由来は、物理学者：

Ernst Ising

です。

1925年、彼は：

> 「磁石はなぜ磁石になるのか？」

を説明するための単純な数学モデルを研究しました。

ただし重要なのは：

* Ising本人は「このモデルでは現実の磁石は説明できない」と結論した
* しかし後の研究者が
  「いや、めちゃくちゃ重要なモデルだった」
  と気づいた

という点です。

つまり：

> 本人より後世の方が重要性を理解したモデル

だったわけです。

数学・物理ではかなりよくある話です。

---

# まずは直感から

Isingモデルでは、

各点が：

* +1
* -1

のどちらかを取ります。

例えば：

```text
+ + - + -
```

みたいな状態です。

物理ではこれを：

* スピン
* 小さな磁石の向き

として扱います。

---

# 重要なのは「隣同士の関係」

Isingモデルの核心はここです。

隣同士が：

* 同じ向きだと嬉しい
* 違う向きだと不安定

と考えます。

つまり：

```text
+ +   ← 安定
- -   ← 安定
+ -   ← 不安定
```

です。

---

# 数式で書くと

典型的なIsingモデルは：

E=-\sum_{(i,j)} J_{ij}s_i s_j

ここで：

* (s_i)：各スピン（+1 or -1）
* (J_{ij})：結合の強さ
* (E)：全体エネルギー

です。

---

# なぜ掛け算なの？

ここが重要です。

スピンは：

* +1
* -1

なので：

| 状態      | 掛け算 |
| ------- | --- |
| +1 × +1 | +1  |
| -1 × -1 | +1  |
| +1 × -1 | -1  |

になります。

つまり：

> 同じ向きなら +1
> 違う向きなら -1

です。

これが：

> 「仲が良い / 悪い」

を自然に表現している。

---

# なぜマイナスが前についている？

式は：

```math
E = - Σ Jij si sj
```

でした。

このマイナスがあるので：

* 同じ向き（+1）
  → エネルギーが低い
* 違う向き（-1）
  → エネルギーが高い

になります。

物理では：

> エネルギーが低い状態ほど安定

です。

つまり：

> 「隣と揃いたがる」

世界になります。

---

# これの何がすごいのか？

ここから急に世界が広がります。

実はIsingモデルは：

* 磁石
* 相転移
* ニューラルネット
* 組合せ最適化
* 量子アニーリング
* QAOA

などに繋がります。

---

# 最適化問題との関係

例えば：

* AさんとBさんは同じチームが良い
* CさんとDさんは別チームが良い

みたいな問題。

これは：

```text
「仲良し関係」を最大化
```

する問題です。

つまり：

> Isingモデルそのもの

になります。

---

# QAOAとの関係

QAOAでは：

> 問題を Ising ハミルトニアンに変換

します。

例えばMaxCut問題なら：

```math
C = \sum_{(i,j)} \frac{1-Z_i Z_j}{2}
```

のような形になります。

ここで (Z_i) は量子版スピンです。

つまりQAOAは：

> 「Isingエネルギー最小化」を量子的に探索する

アルゴリズムとも言えます。

---

# 古典コンピュータとの関係

です。

面白いのはここです。

Isingモデルは単純なのに：

* パターン形成

という現象が現れます。

つまり：

> 「単純な局所ルールから複雑さが生まれる」

最も重要なモデルの一つです。

---

# 相転移とは？

例えば温度を上げると：

```text
+++++++
```

だった整列状態が：

```text
+-++--+-
```

のように崩れます。

これは：

* 磁石になる
* 磁石でなくなる

の境界です。

このような：

> 全体性質が急に変わる現象

を：

Phase Transition

（相転移）

と呼びます。

---

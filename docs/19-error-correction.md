# 1. なぜ量子誤り訂正が必要なのか？

古典コンピュータでは：

ビットは

```
0 or 1
```

のどちらかです。

多少ノイズがあっても：

電圧のしきい値で復元できます。

しかし量子ビットは：

```
α|0⟩ + β|1⟩
```

という連続状態です。

つまり：

* ノイズに弱い
* 状態が壊れやすい
* 観測すると消える

という問題があります。

---

# 2. 量子誤りとは何か？

量子誤りは主に3種類あります：

| 誤り    | 内容    |
| ----- | ----- |
| ビット反転 | 0 ↔ 1 |
| 位相反転  | + ↔ − |
| 両方    | 同時発生  |

古典計算では：

ビット反転だけ

考えればよかったのですが、

量子計算では：

位相反転も同じくらい重要

です。

---

# 3. ビット反転誤りとは何か？

ビット反転誤り：

```
|0⟩ → |1⟩
|1⟩ → |0⟩
```

これは：

Xゲートが勝手に作用した状態

と同じです。

つまり：

```
|ψ⟩ → X|ψ⟩
```

です。

---

# 4. 位相反転誤りとは何か？

位相反転誤り：

```
|+⟩ → |−⟩
```

つまり：

符号が反転します。

これは：

Zゲートが勝手に作用した状態

と同じです。

```
|ψ⟩ → Z|ψ⟩
```

です。

---

# 5. なぜ位相反転が重要なのか？

量子アルゴリズムでは：

位相が計算そのもの

だからです。

例えば：

Grover
QAOA
VQE

では：

干渉が結果を決めます。

つまり：

位相誤り = 計算誤り

になります。

---

# 6. 古典的な誤り訂正の考え方

古典計算では：

繰り返し符号

を使います。

例：

```
0 → 000
1 → 111
```

受信：

```
010
```

なら：

多数決で

```
0
```

と復元できます。

---

# 7. なぜ同じ方法を量子で使えないのか？

理由は：

**量子コピーができない**

からです。

これは：

ノークローン定理

と呼ばれます。

つまり：

```
|ψ⟩ → |ψ⟩|ψ⟩
```

は不可能です。

ここが：

量子誤り訂正の難しさ

です。

---

# 8. 量子誤り訂正の基本アイデア

コピーはできませんが：

**分散エンコード**

はできます。

例：

1量子ビットを

3量子ビットに分散：

```
|0⟩ → |000⟩
|1⟩ → |111⟩
```

これなら：

誤り検出が可能になります。

---

# 9. 3量子ビット符号（ビット反転訂正）

例：

```
|ψ⟩ = α|0⟩ + β|1⟩
```

を

```
α|000⟩ + β|111⟩
```

へ変換します。

もし1ビット壊れて：

```
|010⟩
```

になっても：

補助量子ビットで誤り位置を特定できます。

これを：

**シンドローム測定**

と呼びます。

---

# 10. 位相反転誤りの訂正方法

位相反転は：

そのままでは扱いにくいですが、

基底変換すれば：

ビット反転と同じになります。

具体的には：

Hゲートを使います。

```
H Z H = X
```

つまり：

位相反転誤り

↓

ビット反転誤り

として扱えます。

---

# 11. Shor符号とは何か？

Shor符号は：

最初の完全な量子誤り訂正符号

です。

構造：

```
1量子ビット → 9量子ビット
```

特徴：

| 訂正可能誤り | 内容 |
| ------ | -- |
| ビット反転  | ○  |
| 位相反転   | ○  |
| 同時誤り   | ○  |

つまり：

任意の1量子ビット誤り

を訂正できます。

---

# 12. なぜSurface Codeが重要なのか？

現在もっとも実用に近いのは：

**Surface Code**

です。

理由：

| 特徴       | 内容     |

| 高い耐ノイズ性  | 実験向き   |
| スケーラブル   | 大規模化可能 |

Google

IBM

Quantinuum

などが採用しています。

---

# 13. Surface Codeの直感

Surface Codeでは：

量子ビットを

格子状に配置します：

```
● ● ● ●
● ● ● ●
● ● ● ●
```

そして：

隣接量子ビットだけ

相互作用させます。

これにより：

誤りの位置を検出できます。

---

# 14. フォールトトレラント量子計算とは何か？

誤り訂正の目的は：

単なる修復ではありません。

目標は：

**フォールトトレラント量子計算**

です。

意味：

```
誤りが起きても計算が壊れない
```

という仕組みです。

---

# 15. なぜフォールトトレラントが重要なのか？

理由：

大規模量子計算では

誤りが必ず発生するからです。

例：

```
100万ゲート実行
```

すると：

どこかで必ず誤りが起きます。

したがって：

```
誤り前提の設計
```

が必要になります。

---

# 16. 論理量子ビットとは何か？

誤り訂正では：

複数の物理量子ビット

を使って：

1つの

**論理量子ビット**

を作ります。

例：

```
1論理量子ビット ≒ 数百〜数千物理量子ビット
```

これが：

現在の量子計算の制約です。

# 1. Qiskitで実行できる領域はどこまでか？

まず結論：

これまで扱ってきた内容の大半は **実行可能** です。

例えば：

| 分野             | 実行可否 |
| -------------- | ---- |
| Bell状態         | ✅    |
| Grover         | ✅    |
| QFT（小規模）       | ✅    |
| VQE            | ✅    |
| QAOA           | ✅    |
| Quantum Kernel | ✅    |
| QNN            | ✅    |
| 小規模誤り訂正        | ✅    |

つまり：

第1回〜第18回

まではすべてQiskitで動かせます。

これは重要なポイントです ✨

# 2. ではなぜ第19回以降はコードが減るのか？

理由はシンプルです：

ここから扱っているのは

> 未来の量子コンピュータの内部構造

だからです。

具体例：

* Surface Code
* 論理量子ビット
* Magic State蒸留
* フォールトトレラントTゲート

これらは現在の実機では動きません。

つまり：

**理論設計レイヤー**

に入っています。

---

# 3. 量子コンピュータの階層構造を整理する

量子計算は次の階層構造になっています：

```
量子アルゴリズム
↑
論理ゲート
↑
誤り訂正
↑
物理量子ビット
```

これまで扱ってきたのは：

上2段

でした。

第19回以降は：

下2段

です。

---

# 4. 現在のIBM量子コンピュータの制約

例えば：

IBM Eagle

```
127 physical qubits
```

しかし誤り訂正では：

```
1 logical qubit ≈ 数百〜数千 physical qubits
```

必要になります。

つまり：

論理量子ビットすらまだ作れない

段階です。

---

# 5. Magic State蒸留が実行できない理由

Magic State蒸留は：

実用量子計算の中核技術です。

しかし必要資源：

```
数万〜数百万 physical qubits
```

です。

現在：

```
100 qubits規模
```

したがって：

実機では不可能

になります。

---

# 6. それでもQiskitで誤り訂正は書けるのか？

答え：

はい、書けます 👍

ただし：

教育レベル・研究レベル

になります。

例えば：

## 3量子ビットビット反転符号

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3)

qc.cx(0, 1)
qc.cx(0, 2)

qc.draw("text")
```

これは：

```
|ψ⟩ → α|000⟩ + β|111⟩
```

というエンコード回路です。

概念理解レベル

# 8. Surface Codeはどこまで書ける？

Surface Codeも：

小規模モデルなら可能です。

例えば：

* stabilizer測定
* syndrome抽出
* distance=3 lattice

などです。

ただし：

実運用論理量子ビット

はまだ無理です。

---

# 9. では第19回以降は何を学んでいるのか？

ここで扱っているのは：

量子コンピュータの

**OSレイヤー**

です。

例えるなら：

| 分野           | 対応     |
| ------------ | ------ |
| Python回路     | アプリ    |
| QAOA/VQE     | ミドルウェア |
| 誤り訂正         | OS     |
| Surface Code | カーネル   |

つまり：

量子コンピュータの内部構造

を理解する段階です。

---

# 10. 実はソフトウェアエンジニアほど理解しやすい領域

意外かもしれませんが：

この層は非常にエンジニア的です。

例えば：

| Kubernetes    | Quantum          |
| ------------- | ---------------- |
| container     | physical qubit   |
| pod           | logical qubit    |

Surface Codeは：

量子版Kubernetes

のような存在です 🧩

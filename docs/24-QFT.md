# はじめに

前回は：

> 量子アルゴリズムはどのように設計されるのか？

をテーマに、

* オラクル
* 振幅増幅
* 位相推定

という**量子アルゴリズム設計の共通構造**を整理しました。

今回はその中でも特に重要な：

**量子フーリエ変換（QFT）**

を扱います。

実は：

Shor
位相推定
周期検出
固有値推定

などの中核にはすべて：

QFT

があります。

つまり：

QFTは量子アルゴリズムの「中心装置」

です。

---

# 1. そもそもフーリエ変換とは何か？

フーリエ変換とは：

信号を

時間領域 → 周波数領域

へ変換する操作です。

例：

```
波形
↓
周波数スペクトル
```

つまり：

周期構造を取り出す操作

です。

---

# 2. なぜ周期が重要なのか？

量子アルゴリズムの多くは：

周期を見つける問題

に帰着できます。

例えば：

| 問題         | 本質     |
| ---------- | ------ |
| Shor       | 剰余の周期  |
| 位相推定       | 固有値の周期 |
| HHL        | 固有値構造  |
| 量子シミュレーション | 時間発展周期 |

つまり：

周期検出 = 量子計算の核心

です。

---

# 3. 量子フーリエ変換（QFT）の定義

量子フーリエ変換は：

量子状態に対するフーリエ変換

です。

定義：

QFT,|x\rangle = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} e^{2\pi i xk/N} |k\rangle

意味：

状態 |x⟩ を

すべての基底状態の重ね合わせ

に変換します。

ただし：

位相情報付き

です。

---

# 4. 古典FFTとの違い

古典フーリエ変換：

```
入力：数列
出力：数列
```

量子フーリエ変換：

```
入力：量子状態
出力：量子状態
```

つまり：

測定するまで値は取り出せない

という違いがあります。

---

# 5. QFTの本当の役割

QFTの役割は：

スペクトル解析

ではありません。

役割は：

**位相の読み出し**

です。

つまり：

```
隠れた周期
↓
位相に変換
↓
QFTで抽出
```

という流れです。

---

# 6. 位相推定との関係

位相推定では：

次の関係を扱います：

```
U |ψ⟩ = e^{iθ} |ψ⟩
```

この：

θ

を求めるのが目的でした。

ここで：

QFTが登場します。

構造：

```
制御付きU
↓
干渉
↓
QFT
↓
測定
```

つまり：

QFT = 位相読み出し装置

です。

---

# 7. Shorアルゴリズムとの関係

Shorの核心は：

周期検出

でした。

具体的には：

```
a^x mod N
```

の周期を求めます。

この周期は：

量子状態の位相

として現れます。

そして：

QFTで読み出します。

つまり：

Shor = 位相推定 + QFT

です。

---

# 8. なぜQFTは高速なのか？

古典フーリエ変換：

```
O(N log N)
```

量子フーリエ変換：

```
O((log N)^2)
```

になります。

理由：

量子重ね合わせを利用しているから

です。

つまり：

指数的に圧縮された表現

を操作しています。

---

# 9. QFT回路の構造

QFTは：

Hadamard + 制御位相ゲート

で構成されます。

例（3量子ビット）：

```
H
↓
CR₂
↓
CR₃
↓
H
↓
CR₂
↓
H
```

つまり：

段階的な位相回転

です。

---

# 10. なぜ位相回転で周期が分かるのか？

ここが重要です。

周期を持つ状態：

```
|0⟩ + |r⟩ + |2r⟩ + ...
```

にQFTを適用すると：

```
周期の逆数
```

が強調されます。

つまり：

周期構造が

測定可能な形になる

のです。

---

# 11. QFTは単独では役に立たない

重要なポイント：

QFTだけでは問題は解けません。

必要なのは：

```
位相を埋め込む
↓
QFTで読む
```

という流れです。

つまり：

QFTは読み取り装置

です。

---

# 12. 位相を埋め込むとはどういう意味か？

例：

```
U |ψ⟩ = e^{iθ} |ψ⟩
```

のように：

固有値を位相として表現します。

すると：

```
θ
```

が問題の答えになります。

これを：

QFTで測定します。

---

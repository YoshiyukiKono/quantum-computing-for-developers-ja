# 第3章　測定と確率分布

<!-- 編集元: `docs/04-measurement.md` -->

## はじめに

Hゲートで重ね合わせを作ると、測定するまで結果は確定しません。ここから、量子状態と古典的な測定結果の関係へ踏み込みます。テーマは：

* なぜ観測すると状態が壊れるのか
* 確率はどこから生まれるのか
* 量子回路はなぜ何度も実行するのか

です。これは量子アルゴリズム理解の核心です。

---

## 測定とは何をしているのか？

まず結論から言うと、量子ビットは測定するまで確定した値を持っていません。たとえば次の状態：

```
(|0〉 + |1〉)/√2
```

これは

* 0でもあり
* 1でもある

状態です。しかし測定すると：

```
0 か 1 のどちらか
```

になります。しかも確率は：

```
50% : 50%
```

という1対1の比率です。

---

## なぜ観測すると状態が壊れるのか？

量子ビットは測定前には **重ね合わせ状態** にあります。しかし測定すると：

```
|0〉 または |1〉
```

のどちらかに確定します。これを **波動関数の収縮（wave function collapse）** と呼びます。つまり、測定 = 情報を取り出す操作ではなく、測定 = 状態を変えてしまう操作です。ここが古典ビットとの最大の違いです。

---

## 実際に回路で確認してみる

Hゲートを使って測定を確認します。

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(1, 1)

qc.h(0)
qc.measure(0, 0)

qc.draw("text")
```

意味：

```
|0〉
 ↓
H
 ↓
(|0〉 + |1〉)/√2
 ↓
measure
 ↓
0 or 1
```

つまり、測定すると重ね合わせは消えます。

---

## 確率はどこから生まれるのか？

ここが重要です。量子コンピュータの確率はノイズではありません。誤差でもなく、仕様です。たとえば：

```
(|0〉 + |1〉)/√2
```

なら：

|0〉 → 50%
|1〉 → 50%

になります。別の状態：

```
√0.8|0〉 + √0.2|1〉
```

なら：

|0〉 → 80%
|1〉 → 20%

になります。つまり、振幅の2乗 = 出現確率です。

---

## なぜ量子回路は何度も実行するのか？

ここが実践で最初に戸惑うポイントです。古典プログラム：

```
1回実行 → 1つの結果
```

量子プログラム：

```
1回実行 → ランダムな結果
```

です。そのため、100回、1000回、10000回と繰り返して実行します。例：

```python
from qiskit import Aer, execute

backend = Aer.get_backend("qasm_simulator")

job = execute(qc, backend, shots=1000)

result = job.result()

print(result.get_counts())
```

出力例：

```
{'0': 503, '1': 497}
```

これは確率分布を観測しているという意味です。

---

## なぜ確率分布が重要なのか？

量子アルゴリズムは正しい答えを直接出すのではありません。代わりに、正しい答えが出やすい状態を作るのです。つまり、古典計算：

```
計算 → 答え
```

量子計算：

```
状態生成 → 測定 → 確率的に答え
```

です。量子アルゴリズムとは確率の設計なのです。

---

## Bell状態を測定すると何が起きるか？

Bell状態を測定する例も見てみます：

```
(|00〉 + |11〉)/√2
```

これを測定すると：

```
00
または
11
```

が出ます。しかも：

```
01 は出ない
10 も出ない
```

です。つまり、片方を測定するともう片方も決まります。これが量子もつれです。

---

## ここまでの理解が量子アルゴリズムの入口

ここまでで重要なのは量子計算は値を計算しているのではないということです。代わりに、状態を設計しているのです。そして、測定によって確率として答えが現れるのです。これが：

* Grover探索
* Shorの素因数分解
* 量子機械学習

すべての基礎になります。

---

## まとめ

この章のポイント：

* 測定すると重ね合わせは壊れる
* 確率は振幅の2乗で決まる
* 量子回路は何度も実行する必要がある
* 量子アルゴリズムは確率分布を設計する技術

です。ここまで来ると「量子コンピュータが並列計算のように見える理由」がかなり具体的に理解できてきます

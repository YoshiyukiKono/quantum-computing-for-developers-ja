# 第4章　量子もつれ、CNOT、Bell状態

<!-- 編集元: `docs/03-entanglement.md` -->

この章の単独実行版は `examples/03_bell_state.py` に収録しています。

## はじめに

重ね合わせを複数の量子ビットへ拡張すると、個々の量子ビットだけでは説明できない相関が現れます。この章では量子計算の核心である **量子もつれ（entanglement）** を扱います。ここで初めて、 **古典コンピュータでは表現できない状態** が登場します。

---

## 1. 量子もつれとは何か？

まず直感的に言うと **2つの量子ビットが独立でなくなる状態** です。普通の2ビットなら：

```
00
01
10
11
```

のどれかです。また重ね合わせなら：

```
(|0〉 + |1〉)/√2
```

のように書けます。しかし量子もつれでは **2つの量子ビットを別々に説明できない** 状態が現れます。これが量子計算の本質です。

---

## 2. 例：もっとも有名なもつれ状態（Bell状態）

代表例：

```
(|00〉 + |11〉)/√2
```

これは：

```
両方0
または
両方1
```

が同時に存在する状態です。ここで重要なのは **片方だけでは状態が決まらない** という点です。

---

## 3. 古典計算との違い

例えば古典的な乱数なら：

```
00 または 11
```

は表現できます。しかし：

```
(|00〉 + |11〉)/√2
```

は違います。なぜなら **測定するまで決まっていない** からです。さらに、 **片方を観測するともう片方も決まる** という相関が発生します。これが **量子もつれ** です。

---

## 4. Bell状態を作ってみる

では実際に回路を書きます。

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)

qc.h(0)
qc.cx(0, 1)

qc.measure([0,1], [0,1])

print(qc.draw())
```

ここで重要なのは、次の2つの操作です。まずHadamardゲートを適用します：

```python
qc.h(0)
```

続いてCNOTゲートを適用します：

```python
qc.cx(0,1)
```

---

## 5. Hゲートの役割

まず、次の呼び出しでHadamardゲートを適用します：

```python
qc.h(0)
```

これによって、量子状態は次のように変化します：

```
|0〉 → (|0〉 + |1〉)/√2
```

2量子ビット全体の状態として書くと：

```
(|00〉 + |10〉)/√2
```

---

## 6. CNOTゲートとは何か？

次に：

```python
qc.cx(0,1)
```

です。これは：

```
制御ビットが1なら
ターゲットビットを反転
```

するゲートです。つまり：

```
10 → 11
```

になります。結果として：

```
(|00〉 + |11〉)/√2
```

になります。これが **Bell状態** です。

---

## 7. なぜこれが特別なのか？

ここが最重要ポイントです。次の状態は：

```
(|00〉 + |11〉)/√2
```

```
1つ目の量子ビット
×
2つ目の量子ビット
```

の積として書けません。つまり、**独立な2つの量子ビットではない**ということです。これを **非分離状態** と呼びます。

---

## 8. 実行結果を確認する

この回路を実行すると：

```
00
```

または

```
11
```

だけが出ます。

```
01
10
```

は出ません。つまり、 **必ず同じ値になる** という相関が生まれています。しかしこれは単なる乱数ではありません。なぜなら **測定するまで値は存在しない** からです。

---

## 9. なぜ量子もつれが重要なのか？

量子もつれは **量子計算の計算能力の源** です。例えば：

* 量子テレポーテーション
* Shorのアルゴリズム
* Grover探索
* 量子暗号

すべて、 **もつれ** を使います。逆に言うと **もつれがなければ量子計算は強くならない** とも言えます。

---

## 10. 開発者としての理解ポイント

ここまでの話を整理すると、重ね合わせは **1ビットの拡張**、もつれは **複数ビットの結合** です。つまり、 **状態空間そのものが拡張される** ということです。

---

## まとめ

この章のポイント、Bell状態：

```
(|00〉 + |11〉)/√2
```

は **古典計算では表現できない状態** です。そしてこれを生むのが **CNOTゲート** です。ここで初めて、 **量子コンピュータ特有の計算資源** が登場しました。

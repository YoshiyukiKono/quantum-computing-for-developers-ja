# 第6章　複素数と位相

<!-- 編集元: `docs/06.5-complex-number.md` -->

## はじめに

量子計算では、位相操作が干渉を生みます。ここで重要になるのが **位相（phase）** です。しかし実は **位相は「複素数」が分からないと本質的に理解できない** 概念です。そこでこの章では **量子コンピューティングのための複素数入門** を扱います。数学としてではなく **量子回路を理解するための道具** として説明します。

---

## 1. なぜ量子コンピュータに複素数が出てくるのか？

古典コンピュータでは：

```text
0 or 1
```

だけを扱います。確率モデルでも：

```text
0.2
0.7
0.9
```

のような**実数**を扱います。しかし量子コンピュータでは：

```text
0.6 + 0.8i
```

のような数が出てきます。これは **状態の確率ではなく「振幅」** だからです。重要な関係：

```
確率 = 振幅²（正確には絶対値²）
```

です。つまり、振幅は確率そのものではありません。

---

## 2. そもそも複素数とは何か？

複素数とは：

```
a + bi
```

という形の数です。ここで：

* a：実数部分
* b：虚数部分
* i：√−1

です。例えば：

```
3 + 2i
```

や

```
−1 + 0.5i
```

など。

---

## 3. なぜ √−1 が必要なのか？

普通に考えると：

```
√−1 は存在しない
```

ように思えます。しかし数学では：

```
i = √−1
```

という新しい数を導入します。すると例えば

```
x² + 1 = 0
```

という方程式が解けます。つまり、複素数とは **方程式を自然に解けるようにするために導入された数** です。そして物理学ではこの数が「現実の世界」を非常にうまく表現することが分かりました。その代表例が量子力学です。

---

## 4. 複素数を図で理解する

複素数は数直線ではなく **平面** として表現できます。普通の数：

```
3
```

は横方向だけでした。複素数：

```
3 + 2i
```

は、平面上で次の座標を表します：

* 横：3
* 縦：2

になります。つまり：

```
複素数 = 平面上の点
```

です。これを **複素平面** と呼びます。

---

## 5. 複素数の本当に重要な意味（長さと角度）

複素数は **位置** として見ることもできますが、量子コンピューティングでは：

```
長さ + 角度
```

として見るのが重要です。例えば：

```
1 + 0i
```

は長さ = 1角度 = 0°です。一方：

```
0 + 1i
```

は長さ = 1角度 = 90°になります。つまり、複素数とは **長さと回転を同時に表す数** なのです。

---

## 6. 位相とは「角度」のこと

ここで重要なのは、次の量子状態です：

```
|ψ〉 = α|0〉 + β|1〉
```

この式の係数：

```
α
β
```

はいずれも複素数です。つまり、それぞれが

```
長さ + 角度
```

を持っています。この、角度が **位相（phase）** です。

---

## 7. なぜ位相が重要なのか？

量子コンピュータでは確率は

```
|α|²
```

で決まります。ここに角度は出てきません。例えば、次の2つの状態を比べます：

```
|1〉
```

一方：

```
−|1〉
```

どちらも測定確率は同じです。しかし、干渉では違いが出ます。次の2つも比べてみましょう：

```
|0〉 + |1〉
```

一方：

```
|0〉 − |1〉
```

は測定確率は同じですが、次に Hadamard をかけると結果が変わります。つまり **位相は測定では見えないが計算では効く** のです。ここが量子アルゴリズムの核心です。

---

## 8. 位相＝回転操作

複素数は回転として理解できます。例えば、$1$ に $i$ を掛けると $i$ になり、複素平面上で90°回転します。さらにもう一度 $i$ を掛けると $-1$ になり、さらに90°回転します。まとめると、**複素数の掛け算は回転**です。

---

## 9. 量子ゲートは回転装置である

量子ゲートとは何か？実は **状態ベクトルを回転させる操作** です。例えば、Zゲート：

```
|0〉 → |0〉
|1〉 → −|1〉
```

これは、**|1〉だけを180°回転させる**操作です。つまり、Zゲートは **位相回転ゲート** です。

---

## 10. Hadamardゲートも回転

Hadamard：

```
|0〉 → |0〉 + |1〉
```

これは状態空間の中で回転を起こしています。量子回路とは **回転の組み合わせ** なのです。

---

## 11. なぜ実数ではダメなのか？

重要な疑問、なぜ複素数が必要なのか？答えは **干渉を作るため** です。もし振幅が実数だけならできる操作は

**符号反転**

程度に制限されます。しかし複素数なら **任意の角度回転** ができます。つまり、 **干渉を自由に設計できる** のです。これが量子アルゴリズムを可能にしています。

---

## 12. Groverアルゴリズムとの関係

Groverアルゴリズムでは、次の2つの操作を行います。

1. 正解状態の位相を反転する
2. 全体を干渉させる

これらは実際には **複素数の回転** を利用しています。つまり、Groverとは **位相を設計するアルゴリズム** なのです。

---

## まとめ

この章で理解したことは次のとおりです。

- 複素数とは何か
- 複素数は平面上の点として表せる
- 複素数は長さと角度を持つ
- 位相とは角度のことである
- 量子ゲートは回転操作である
- 干渉は位相差から生まれる

つまり、**量子コンピュータとは「複素数を操作する計算機」**です。ここまで理解できれば、量子回路がなぜ動くのかが見えるようになります。

---

## コラム：複素数はなぜ発明されたのか？そしてなぜ役に立つのか

ここまで読んで、多くの人がこう思ったはずです **√−1 なんて本当に必要なの？** 実は複素数は **最初は誰も信じていなかった数** でした。しかし現在では：

* 電気工学
* 信号処理
* 制御理論
* 量子力学
* 量子コンピューティング

のすべてに不可欠です。なぜそうなったのかを見てみましょう。

---

## 1. 複素数は「方程式を解くため」に生まれた

複素数の起源は16世紀です。三次方程式：

$$
x^3 + ax + b = 0
$$

を解こうとした数学者たちが、途中で

$$
\sqrt{-1}
$$

に出会いました。代表的な人物：

* Gerolamo Cardano
* Rafael Bombelli

彼らは最初、 **計算途中に変な数が出るけど最後は消えるから問題ない** と考えました。虚数は **計算途中だけ現れる謎の数** だと捉えられていたのです。

---

## 2. 「虚数」は長い間疑われていた

当時の数学者は、これを **imaginary number（想像上の数）** と呼びました。

つまり **本当に存在しない数** だと思われていました。しかし18世紀になると、Leonhard Eulerが革命的な式を発見します：

$$
e^{i\theta} = \cos\theta + i\sin\theta
$$

これは **指数関数と三角関数がつながる** という驚くべき結果でした。ここで初めて：

```text
複素数 = 回転
```

という意味が見えてきました。

---

## 3. 複素数は「平面の回転」を表す数だった

さらに19世紀、Carl Friedrich Gaussは **複素数は平面上の点として理解できる** ことを示しました。これによって、 **意味不明の数** だった虚数は **幾何学的に意味を持つ数** になりました。ここから、複素数は数学の中心的存在になります。

---

## 4. 電気工学が複素数を「現実の道具」に変えた

複素数が本当に重要になったのは、19世紀後半の電気工学です。交流電流は：

$$
V(t) = V_0 \sin(\omega t)
$$

のように振動します。これを扱うとき、複素数を使うと計算が劇的に簡単になります。例えば：

* フーリエ変換
* フィルタ設計
* 通信理論
* 制御理論

すべて複素数で書かれています。つまり **現代の電子機器は複素数で動いている** と言っても過言ではありません。

---

## 5. そして量子力学が決定的だった

20世紀に入ると、Erwin Schrödingerが導入した波動関数：

$$
\psi(x,t)
$$

は複素数でした。ここで重要なのは **自然そのものが複素数で動いている** という事実です。量子状態は：

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle
$$

のように書かれますが、この

$$
\alpha,\beta
$$

が複素数である理由は数学の都合ではなく **物理の要請** です。

---

## 6. 量子コンピュータは「複素数を直接計算する装置」

古典コンピュータでは **ビットを操作する**。

量子コンピュータでは **複素振幅を操作する** と言えます。つまり、量子ゲートとは

**複素平面上の回転操作** です。そして、干渉とは

**回転の差** です。さらに、Groverアルゴリズムとは

**位相回転を設計するアルゴリズム** です。

---

## 7. 「役に立たない数学」が世界を変える典型例

複素数の歴史は面白い教訓を示しています。16世紀には **意味不明の数** と位置づけられました。

18世紀には **便利な計算道具** と位置づけられました。

19世紀には **幾何学的対象** と位置づけられました。

20世紀には **物理の基本言語** と位置づけられました。

21世紀には **量子コンピュータの基盤** と位置づけられました。

つまり **最も抽象的な数学が最も実用的になる** という典型例です。そして今、私たちはその最前線にいます。

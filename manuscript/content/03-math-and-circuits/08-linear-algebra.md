# 第8章　量子計算を支える線形代数

<!-- 編集元: `docs/25-linear-algebra.md` -->

## はじめに

ここまでの各章で：

* 量子ビット
* 重ね合わせ
* 干渉
* Grover
* QAOA / VQE
* 位相推定
* QFT

などを扱ってきました。

ここまで来ると気づくことがあります **量子計算はほとんど線形代数で書かれている**

実際その通りです。

量子計算とは **線形代数そのもの** です。

この章では **開発者視点で理解する量子計算の線形代数構造** を整理します。

扱うテーマ：

* 状態ベクトルとは何か
* ユニタリ行列とは何か
* 固有値問題と量子アルゴリズム
* テンソル積の意味
* なぜ量子計算は線形代数なのか

ここを理解すると、**量子アルゴリズムの構造が一気に見通せるようになります**。

---

## 1. 量子状態はベクトルである

量子ビットは **ビットではありません**。

ベクトルです。

例えば：

```
|ψ〉 = α|0〉 + β|1〉
```

これは **2次元複素ベクトル空間の要素** です。

つまり：

```
|ψ〉 = (α, β)
```

と同じ意味です。

条件：

```
|α|² + |β|² = 1
```

確率保存の条件です。

---

## 2. 量子ゲートは行列である

量子ゲートは **関数ではありません**。

行列です。

例：

Hadamardゲート

```
H =
1/√2 [ 1   1
       1  -1 ]
```

つまり：

量子計算とは

```
ベクトル × 行列
```

の繰り返しです。

---

## 3. なぜ量子ゲートはユニタリなのか？

量子ゲートは必ず **ユニタリ行列** です。

定義：

U^{\dagger} U = I

意味は **長さ（確率）が保存される** ということです。

つまり、**量子状態は回転しているだけ** です。

---

## 4. 回転としての量子計算

量子計算は **状態空間の回転** として理解できます。

例：

```
|0〉
↓
H
↓
(|0〉 + |1〉)/√2
```

これは **45度回転** です。

つまり、**量子計算 = 幾何操作** です。

---

## 5. 固有値問題とは何か？

量子アルゴリズムの中心には **固有値問題** があります。

形式：

```
A|ψ〉 = λ|ψ〉
```

ここで：

|ψ〉 = 固有ベクトル
λ = 固有値です。

---

## 6. なぜ固有値が重要なのか？

量子計算では **答えが固有値として現れる** ことが多いからです。

例：

| アルゴリズム | 求めているもの  |
| ------ | -------- |
| 位相推定   | 固有値      |
| HHL    | 固有値      |
| VQE    | 最小固有値    |
| 量子化学   | エネルギー固有値 |

つまり：

量子計算とは

固有値探索装置です。

---

## 7. 位相と固有値の関係

量子計算では **固有値は位相として表れます**。

形式：

```
U|ψ〉 = e^{iθ}|ψ〉
```

つまり：

固有値

=

位相です。

そして、**QFTがこれを読み出します**。

---

## 8. テンソル積とは何か？

量子計算でもう一つ重要なのが **テンソル積** です。

2量子ビット：

```
|ψ〉 ⊗ |φ〉
```

例えば：

```
|0〉 ⊗ |1〉 = |01〉
```

という対応です。

---

## 9. なぜテンソル積が必要なのか？

複数量子ビットを扱うためです。

古典ビット：

```
2ビット → 4状態
```

量子ビット：

```
2量子ビット → 4次元ベクトル
```

つまり、**状態空間が指数的に増えます**。

---

## 10. n量子ビットの状態空間

重要な式：

```
n qubits → 2^n 次元空間
```

例えば：

| qubit数 | 次元    |
| ------ | ----- |
| 1      | 2     |
| 2      | 4     |
| 10     | 1024  |
| 50     | 約10¹^5 |

ここに **量子計算の強さがあります**。

---

## 11. エンタングルメントとテンソル積

エンタングルメントとは **テンソル分解できない状態** です。

例：

```
(|00〉 + |11〉)/√2
```

これは：

```
|ψ〉 ⊗ |φ〉
```

の形に分解できません。

つまり、**独立ではない状態** です。

---

## 12. なぜエンタングルメントが重要なのか？

理由は **指数的状態空間を使えるから** です。

古典：

```
2ビット → 2状態ずつ独立
```

量子：

```
2量子ビット → 4状態同時
```

つまり、**情報表現能力が違います**。

---

## 13. 線形結合としての量子アルゴリズム

量子状態：

```
|ψ〉 = Σ α_i |i〉
```

量子ゲート：

```
|ψ'〉 = U|ψ〉
```

つまり、**線形変換** です。

すべてが **線形結合の操作** です。

---

## 14. なぜ非線形操作が存在しないのか？

重要な事実として、**量子計算は線形です**。

つまり：

```
U(α|0〉 + β|1〉)
=
αU|0〉 + βU|1〉
```

という線形性を持ちます。

これが **量子アルゴリズム設計の制約** になります。

---

## 15. 測定だけが非線形である

唯一の例外は **測定** です。

測定：

```
|ψ〉 → |0〉 または |1〉
```

これは **非線形操作です**。

つまり：

量子計算の非線形性は

測定に集中しています。

---

## 16. 幾何としての量子状態空間

量子状態は **球面上の点** として理解できます。

例：

Bloch球

```
|0〉
|1〉
|+〉
|−〉
```

すべて **球面上の点です**。

つまり：

量子計算は

球面回転です。

---

## 17. 線形代数として見た量子アルゴリズム

整理すると：

| 操作        | 線形代数  |
| --------- | ----- |
| 状態        | ベクトル  |
| ゲート       | 行列    |
| 合成        | 行列積   |
| 観測        | 射影    |
| エンタングルメント | テンソル積 |
| 位相推定      | 固有値問題 |

つまり、**量子計算 = 線形代数** です。

---

## まとめ

この章のポイント：

* 量子状態はベクトル
* 量子ゲートはユニタリ行列
* 量子計算は回転操作
* 多くのアルゴリズムは固有値問題
* テンソル積で状態空間が指数拡張される
* エンタングルメントは分解不能状態
* 測定だけが非線形操作

ここまでで、**量子計算の数学的コア構造** が見えてきました。

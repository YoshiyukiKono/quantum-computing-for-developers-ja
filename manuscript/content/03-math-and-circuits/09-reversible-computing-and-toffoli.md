# 第9章　古典計算、可逆計算、Toffoliゲート

<!-- 編集元: `docs/26-classic-reversible-quantum.md` -->
## はじめに

ここまでに扱った内容 **量子計算と線形代数はどのようにつながっているのか？**

をテーマに、

* 状態＝ベクトル
* ゲート＝ユニタリ行列
* 固有値問題
* テンソル積
* 測定の非線形性

という**量子計算の数学的基盤**を整理しました。

ここではその先へ進み **量子計算は古典計算とどう違うのか？**

ではなく、

**量子計算は古典計算をどう拡張しているのか？**

という視点で整理します。

扱うテーマ：

* 可逆計算とは何か？
* なぜ量子計算は可逆なのか？
* Toffoliゲートの意味
* 古典回路と量子回路の関係
* 量子計算はどこまで古典を含むのか？

ここを理解すると：

量子回路は「別物」ではなく
**古典回路の自然な拡張**

であることが見えてきます。

---

## 1. 古典計算は本来「不可逆」である

例えば：

```
AND(1,1) = 1
AND(0,1) = 0
```

出力が同じでも **入力が複数存在します**。

つまり：

```
出力 → 入力
```

は一意に決まりません。

これを **不可逆計算** と呼びます。

---

## 2. しかし量子計算は不可逆を許さない

量子ゲートはすべて **ユニタリ行列** でした。

つまり、**常に逆操作が存在します**。

例：

```
H^-¹ = H
```

したがって：

量子計算は必ず

**可逆計算** になります。

---

## 3. なぜ量子計算は可逆なのか？

理由は物理です。

量子力学の時間発展は：

可逆

だからです。

量子状態は **時間を逆にすれば元に戻ります**。

つまり：

```
現在 → 過去
```

が再構成できます。

これが **量子ゲート＝可逆** の理由です。

---

## 4. 可逆計算とは何か？

可逆計算とは **入力が出力から復元できる計算** です。

例：

```
x → (x, f(x))
```

これは可逆です。

なぜなら、**x が保存されているからです**。

---

## 5. NOTゲートは可逆である

古典ゲートでも **NOT** は可逆です。

```
0 → 1
1 → 0
```

逆操作：

```
1 → 0
0 → 1
```

つまり、**NOT = 可逆ゲート** です。

---

## 6. ANDゲートを可逆にする方法

ANDは不可逆でした：

```
(x, y) → x AND y
```

しかし：

次のようにすると可逆になります：

```
(x, y, 0) → (x, y, x AND y)
```

入力が保存されています。

つまり、**可逆化できる** のです。

---

## 7. Toffoliゲートとは何か？

ここで登場するのが **Toffoliゲート** です。

構造：

```
(x, y, z) → (x, y, z ⊕ xy)
```

つまり：

```
if x = 1 and y = 1:
    z を反転
```

という動作です。

これは **可逆ANDゲート** です。

---

## 8. なぜToffoliゲートが重要なのか？

理由：

Toffoliゲートだけで

古典計算がすべて実装できる

からです。

つまり：

```
古典計算 ⊂ 可逆計算
```

が成立します。

さらに：

```
可逆計算 ⊂ 量子計算
```

という包含関係です。

つまり：

```
古典計算 ⊂ 量子計算
```

という関係まで成り立ちます。

---

## 9. 量子計算は古典計算を包含している

重要な関係：

```
classical ⊂ reversible ⊂ quantum
```

つまり：

量子回路は

古典回路の上位互換です。

---

## 10. CNOTゲートは古典XORである

CNOT：

```
(x, y) → (x, x ⊕ y)
```

これは：

XOR

そのものです。

つまり：

量子ゲートの一部は

古典ゲートと同じです。

---

## 11. Hadamardゲートが古典計算と違う理由

Hadamard：

```
|0〉 → (|0〉 + |1〉)/√2
```

これは **重ね合わせ** を作ります。

古典計算では **存在しない操作** です。

つまり、**ここが境界です**。

---

## 12. 古典回路は量子回路の特殊ケース

量子回路：

```
重ね合わせ OK
干渉 OK
エンタングルメント OK
```

古典回路：

```
重ね合わせ NG
干渉 NG
エンタングルメント NG
```

つまり、**量子回路の制限版** です。

---

## 13. 可逆計算が重要になる理由

実は、**未来のコンピュータ設計でも重要です**。

理由は **エネルギー消費の下限があるからです**。

ランドアウアーの原理：

```
1ビット消去 = 最小エネルギー消費
```

つまり、**不可逆計算は発熱する** のです。

可逆計算は **理論上ゼロ消費** になります。

---

## 14. 量子計算と熱力学の関係

量子計算が可逆なのは：

熱を出さない計算

だからです。

つまり：

```
情報 = 物理
```

という関係が成立します。

これは **量子情報理論の基本原理です**。

---

## 15. 古典アルゴリズムは量子回路で書けるのか？

答えは **書けます**。

方法：

```
AND → Toffoli
XOR → CNOT
NOT → X
```

で置き換えるだけです。

つまり、**すべて量子回路化できます**。

---

## 16. では量子アルゴリズムは何が違うのか？

違いは **重ね合わせ** です。

例えば、**古典では 1つの入力 です**。

量子では **すべての入力** を同時に扱います。

---

## 17. しかし並列計算ではない

よくある誤解は、**量子計算＝並列計算** というものです。しかし、これは正確ではありません。

正確には：

```
重ね合わせ
＋
干渉
```

という要素です。

つまり：

不要な解を消し
正しい解を強調する

計算です。

---

## 18. 可逆計算として見た量子アルゴリズム

量子アルゴリズムの構造：

```
入力保存
↓
位相操作
↓
干渉
↓
測定
```

つまり、**可逆操作＋測定** です。

---

## まとめ

この章のポイント：

* 古典計算は基本的に不可逆
* 量子計算は完全に可逆
* Toffoliゲートで古典計算を再現できる
* 古典計算は量子計算に含まれる
* 重ね合わせが量子計算の核心
* 干渉が高速化の源泉
* 可逆計算は熱力学とも関係する

ここまでで、**古典計算と量子計算の統一構造** が見えてきました。

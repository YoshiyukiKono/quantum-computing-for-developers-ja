---

## 1. QAOA回路の全体像

QAOAは次の操作を繰り返します：

```
① 初期状態生成
② コストハミルトニアン作用
③ ミキサーハミルトニアン作用
④ 測定
⑤ パラメータ更新（古典最適化）
```

数学的には：

```
U(B,β) U(C,γ)
```

を交互に適用します。

ここで：

* γ：コスト角度
* β：ミキサー角度

が主要なパラメータです。

---

## 2. Max-Cut問題の定式化

Max-Cutでは **異なるグループに属する頂点ペア** を最大化します。

量子表現では：

Z演算子を使って次のように書けます：

H_C = \sum_{(i,j)\in E} \frac{1 - Z_i Z_j}{2}

意味：

| 状態      | 値 |
| ------- | - |
| 同じグループ  | 0 |
| 異なるグループ | 1 |

つまり、**Cutされた辺の数** をそのままエネルギーとして表現できます。

---

## 3. ミキサーハミルトニアン

探索空間を広げる役割を持つのが **ミキサーハミルトニアン** です。

最も基本形は：

H_B = \sum_i X_i

意味：

すべての量子ビットに

X回転をかけるということです。

直感：

```
Z方向 → 解の評価
X方向 → 解の探索
```

という役割になります。

---

## 4. 最小構成：2ノードMax-Cut

対象グラフ：

```
0 ---- 1
```

辺は1本だけです。

したがって：

```
H_C = (1 − Z_0Z_1)/2
```

という形になります。

---

## 5. QAOA回路の構造（p=1）

最も基本のQAOAは **p = 1** です。

回路構造：

```
|0〉 → H → Cost → Mixer → Measure
|0〉 → H → Cost → Mixer → Measure
```

つまり：

```
H⊗n
↓
U(C,γ)
↓
U(B,β)
```

と表します。

---

## 6. Qiskitで回路を書く

まず必要なライブラリ：

```python
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
```

パラメータ定義：

```python
gamma = Parameter("γ")
beta = Parameter("β")
```

回路生成：

```python
qc = QuantumCircuit(2)
```

---

## 7. 初期状態の生成

すべての量子ビットを **均等重ね合わせ** にします。

```python
qc.h(0)
qc.h(1)
```

状態：

```
(|00〉 + |01〉 + |10〉 + |11〉)/2
```

探索のスタート地点です。

---

## 8. コストハミルトニアンの実装

次の演算：

```
exp(-i γ Z_0Z_1)
```

は回路として：

```
CNOT
RZ
CNOT
```

で実装できます。

Qiskitコード：

```python
qc.cx(0, 1)
qc.rz(2 * gamma, 1)
qc.cx(0, 1)
```

これが **U(C,γ)** です。

---

## 9. ミキサーハミルトニアンの実装

次の演算：

```
exp(-i β X)
```

は、次の回転に対応します：

RX回転

として実装できます。

```python
qc.rx(2 * beta, 0)
qc.rx(2 * beta, 1)
```

これが **U(B,β)** です。

---

## 10. 完成したQAOA回路

まとめると：

```python
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

gamma = Parameter("γ")
beta = Parameter("β")

qc = QuantumCircuit(2)

# 初期状態
qc.h(0)
qc.h(1)

# コストハミルトニアン
qc.cx(0, 1)
qc.rz(2 * gamma, 1)
qc.cx(0, 1)

# ミキサーハミルトニアン
qc.rx(2 * beta, 0)
qc.rx(2 * beta, 1)

qc.measure_all()

qc.draw("text")
```

これで、**最小構成のQAOA回路** が完成です。

---

## 11. 実行の流れ（ハイブリッド最適化）

QAOAは **量子だけでは完結しません**。

流れ：

```
γ, β を仮定
↓
量子回路実行
↓
期待値計算
↓
古典最適化
↓
γ, β 更新
↓
繰り返し
```

つまり、**量子 × 古典** の協調アルゴリズムです。

---

## 12. 測定結果の解釈

測定すると：

```
00
01
10
11
```

のいずれかが出ます。

Max-Cutでは：

```
01
10
```

が正解です。

最適なパラメータでは **この確率が最大になります**。

つまり、 **正解の確率を干渉で強調する** のがQAOAです。

---

## コードへの補足

このコード単体は、まだ「量子側だけ」を書いています。
QAOA（Quantum Approximate Optimization Algorithm）の本体は、

**量子回路で候補解を生成 → 古典コンピュータで評価・調整 → また量子回路を実行**

を繰り返す「ループ構造」にあります。

まだ、このコードは、

**「量子部分の1回分の回路」** です。

---

## まず、このコードが何をしているか

QAOAは本質的には **「良い解」を強める量子干渉を作る**

アルゴリズムです。

---

### 1. 初期状態

```python
qc.h(0)
qc.h(1)
```

Hadamardで：

```math
|00〉 → \frac{1}{2}(|00〉 + |01〉 + |10〉 + |11〉)
```

全候補を同時に持つ状態を作ります。

ここで：

* 00
* 01
* 10
* 11

は「最適化問題の候補解」です。

---

## 2. コストハミルトニアン

```python
qc.cx(0, 1)
qc.rz(2 * gamma, 1)
qc.cx(0, 1)
```

ここが **「良い解」と「悪い解」に位相差を与える**

部分です。

QAOAでは：

* 良い解 → 位相を強調
* 悪い解 → 位相をずらす

ことで、後の干渉で確率差を作ります。

---

## 3. ミキサー

```python
qc.rx(2 * beta, 0)
qc.rx(2 * beta, 1)
```

ここは **状態を混ぜる**

部分です。

Groverっぽく言えば：

* コストで「印」をつけ
* ミキサーで「干渉」させる

イメージ。

---

## ここまで全部「量子」

重要なのは：

```python
gamma = Parameter("γ")
beta = Parameter("β")
```

ここ。

γ と β は、

**まだ決まっていない** のです。

つまりこの回路は **「どのくらい回転すれば最適解が強調されるか」**

まだ知らない。

---

## 古典部分はどこ？

実際のQAOAでは：

1. γ, β を適当に入れる
2. 回路を実行
3. 結果を測定
4. 「どのくらい良い解が出たか」を古典計算で評価
5. γ, β を更新
6. また回路実行

を繰り返します。

つまり：

```text
古典CPU:
    γ, β を決める
        ↓

量子回路:
    候補解を生成
        ↓

測定:
    ビット列取得
        ↓

古典CPU:
    スコア計算
    γ, β 更新
```

という反復処理です。

---

## ここがQAOAの本質

QAOAは：

```text
量子:
    巨大な状態空間を並列探索

古典:
    パラメータ最適化
```

のハイブリッド。

つまり **量子回路そのものを、古典最適化器が学習する**

構造です。

これはかなり「機械学習」に近い。

---

## 実際にはこう書く

Qiskitでは通常：

```python
from scipy.optimize import minimize
```

などを使って、

```python
cost(gamma, beta)
```

を最小化します。

概念的には：

```python
while not converged:

    result = quantum_run(gamma, beta)

    score = classical_evaluate(result)

    gamma, beta = classical_optimizer(score)
```

という流れです。

---

## 面白い点

QAOAは、

**量子コンピュータ単独** ではありません。

むしろ：

```text
量子回路を、
古典コンピュータが訓練する
```

アルゴリズム。

だから現在のNISQ時代で重要視されています。

---

## なぜこの構造になった？

完全量子計算（Shorなど）は：

* 深い回路
* 大量量子ビット
* 誤り訂正

が必要。

しかし現在の量子機械は弱い。

そこで **「難しい探索だけ量子にやらせよう」** という発想になった。

QAOAやVQEはその代表。

---

## さらに本質的にいうと

QAOAは **量子状態空間の地形** を、

**古典最適化** で登るアルゴリズムです。

γ と β は **「量子干渉の形」**

そのものを制御しています。

つまり古典コンピュータは **「どんな干渉パターンを作れば、最適解が浮かび上がるか」**

を探している。

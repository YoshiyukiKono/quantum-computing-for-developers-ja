# 第29章　Qiskitで扱える範囲と抽象化の境界

<!-- 編集元: `docs/20.5-Qiskit-coverage.md` -->
## はじめに

誤り訂正とフォールトトレラント量子計算へ進むと、

**Pythonコードが急に減った？**

と感じた方も多いと思います。

これは偶然ではありません。

実はここから先は **現在の量子コンピュータではまだ実行できない層** を扱い始めています。

この章では：

* Qiskitで実行できる範囲
* 実行できない範囲
* なぜコードが減るのか
* それでも学ぶ意味はあるのか
* これから実装可能な誤り訂正の例

を整理します。

---

## 1. Qiskitで実行できる領域はどこまでか？

まず結論として、**これまで扱ってきた内容の大半は 実行可能 です**。

例えば：

| 分野             | 実行可否 |
| -------------- | ---- |
| Bell状態         | 可能    |
| Grover         | 可能    |
| QFT（小規模）       | 可能    |
| VQE            | 可能    |
| QAOA           | 可能    |
| Quantum Kernel | 可能    |
| QNN            | 可能    |
| 小規模誤り訂正        | 可能    |

つまり：

第I部〜第V部の実装例

まではすべてQiskitで動かせます。

これは重要なポイントです

---

## 2. なぜ誤り訂正以降はコードが減るのか？

理由はシンプルです：

ここから扱っているのは

**未来の量子コンピュータの内部構造**

だからです。

具体例：

* Surface Code
* 論理量子ビット
* Magic State蒸留
* フォールトトレラントTゲート

これらは現在の実機では動きません。

つまり、**理論設計レイヤー** に入っています。

---

## 3. 量子コンピュータの階層構造を整理する

量子計算は次の階層構造になっています：

```
量子アルゴリズム
↑
論理ゲート
↑
誤り訂正
↑
物理量子ビット
```

これまで扱ってきたのは **上2段** でした。

誤り訂正以降は **下2段** です。

---

## 4. 現在のIBM量子コンピュータの制約

例えば：

IBM Eagle

```
127 physical qubits
```

しかし誤り訂正では：

```
1 logical qubit ≈ 数百〜数千 physical qubits
```

必要になります。

つまり：

論理量子ビットすらまだ作れない

段階です。

---

## 5. Magic State蒸留が実行できない理由

Magic State蒸留は **実用量子計算の中核技術です**。

しかし必要資源：

```
数万〜数百万 physical qubits
```

という規模です。

現在は **100 qubits規模** です。

したがって、**実機では不可能** になります。

---

## 6. それでもQiskitで誤り訂正は書けるのか？

答え：

はい、書けます

ただし、**教育レベル・研究レベル** になります。

例えば：

### 3量子ビットビット反転符号

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3)

qc.cx(0, 1)
qc.cx(0, 2)

qc.draw("text")
```

これは：

```
|ψ〉 → α|000〉 + β|111〉
```

というエンコード回路です。

---

## 7. Shor符号も実装できる

簡略版なら：

Shor符号（9qubit）

もQiskitで書けます。

つまり、 **概念理解レベル** です。

の誤り訂正は実装可能です。

---

## 8. Surface Codeはどこまで書ける？

Surface Codeも **小規模モデルなら可能です**。

例えば：

* stabilizer測定
* syndrome抽出
* distance=3 lattice

などです。

ただし、**実運用論理量子ビット** はまだ無理です。

---

## 9. 誤り訂正以降では何を学ぶのか？

ここで扱っているのは：

量子コンピュータの

**OSレイヤー** です。

例えるなら：

| 分野           | 対応     |
| ------------ | ------ |
| Python回路     | アプリ    |
| QAOA/VQE     | ミドルウェア |
| 誤り訂正         | OS     |
| Surface Code | カーネル   |

つまり、**量子コンピュータの内部構造** を理解する段階です。

---

## 10. 実はソフトウェアエンジニアほど理解しやすい領域

意外かもしれませんが **この層は非常にエンジニア的です**。

例えば：

| Kubernetes    | Quantum          |
| ------------- | ---------------- |
| container     | physical qubit   |
| pod           | logical qubit    |
| scheduler     | decoder          |
| control plane | error correction |

Surface Codeは：

量子版Kubernetes

のような存在です

---

## 11. Pythonコードを続けたいなら何をやるべきか？

この段階でも実装できるテーマはあります：

おすすめ：

* repetition code
* phase flip code
* Shor code（簡略版）
* stabilizer measurement
* syndrome decoding

つまり、**誤り訂正のミニモデル** です。

---

## 12. 次に実装するならこれが自然

学習の自然な流れは **Qiskitで量子誤り訂正を実装する** ことです。

内容例：

* 3qubit bit-flip code
* phase-flip code
* Shor code
* stabilizer測定
* syndrome decoding

これを実装すると：

Surface Code理解が一気に深まります

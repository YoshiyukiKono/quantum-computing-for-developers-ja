# 第30章　量子優位性と計算量の境界

<!-- 編集元: `docs/21-quantum-advantage.md` -->

## はじめに

ここまでの各章で：

* 量子ビット
* 量子ゲート
* 干渉
* Groverアルゴリズム
* QAOA
* VQE
* 量子機械学習
* 量子誤り訂正
* logical qubit

まで扱ってきました。

つまりここまで読み進めた時点で、すでに **量子計算を「書ける」状態** になっています。

ここで自然に生まれる疑問があります **量子コンピュータは本当にどこで速くなるのか？**

この章のテーマは **量子優位性（Quantum Advantage）** です。

---

## 1. 量子優位性とは何か？

量子優位性とは：

古典コンピュータでは現実的時間で解けない問題を
量子コンピュータが現実的時間で解ける

ことを指します。

つまり：

```
量子コンピュータ > 古典コンピュータ
```

が成立する問題領域です。

重要なのは **すべての問題が速くなるわけではない** という点です。

---

## 2. 量子コンピュータは万能ではない

よくある誤解 **量子コンピュータは何でも高速になる**

これは誤りです。

例えば：

| 問題          | 量子優位性 |
| ----------- | ----- |
| ソート         | なし     |
| 検索（一般）      | なし     |
| 行列計算        | なし     |
| 暗号解読（RSA）   | あり     |
| 組合せ探索       | 条件付き     |
| 量子系シミュレーション | あり     |

つまり、**問題の種類によって変わる** のです。

---

## 3. 計算量理論から見た量子計算

ここで登場するのが **計算量クラス** です。

代表的なもの：

| クラス | 意味      |
| --- | ------- |
| P   | 高速に解ける  |
| NP  | 検証が高速   |
| BPP | 確率的古典計算 |
| BQP | 確率的量子計算 |

ここで重要なのは **BQP** です。

---

## 4. BQPとは何か？

BQPとは：

```
Bounded-error Quantum Polynomial time
```

の略です。

意味：

量子コンピュータで
多項式時間で
高確率に解ける問題です。

つまり、 **量子コンピュータが得意な問題の集合** です。

---

## 5. 古典計算との関係

現在の理解では：

```
P ⊆ BPP ⊆ BQP
```

と考えられています。

そして、 **NP と BQP の関係は未解決**。

これは非常に重要です。

つまり、**量子コンピュータがNP完全問題を解けるか**？ はまだ分かっていません。

---

## 6. Shorアルゴリズムの位置づけ

Shorアルゴリズムは **代表的なBQP問題です**。

内容は **整数因数分解** です。

古典計算：

準指数時間

量子計算：

多項式時間

つまり、**明確な量子優位性があります**。

そしてこれは **RSA暗号に影響します**。

---

## 7. Groverアルゴリズムの位置づけ

Groverは **探索問題を高速化します**。

古典：

```
O(N)
```

量子：

```
O(√N)
```

つまり：

指数高速化ではない

しかし、**実用上は非常に強力です**。

例えば：

* パスワード探索
* 最適解探索
* データベース検索

などに応用可能です。

---

## 8. QAOAの位置づけ

QAOAは **組合せ最適化問題向けのアルゴリズムです**。

例：

* Max-Cut
* 配送最適化
* スケジューリング
* ポートフォリオ最適化

ただし、**理論的優位性はまだ未証明** です。

現在は **NISQ時代の有力候補** という位置づけです。

---

## 9. VQEの位置づけ

VQEは **量子化学向けアルゴリズムです**。

用途：

* 分子構造解析
* 材料設計
* 触媒開発
* 創薬

これは **最初に実用化される可能性が高い分野** と考えられています。

理由は **自然界が量子だから** です。

---

## 10. なぜ量子シミュレーションが強いのか？

古典コンピュータ：

量子状態を指数サイズで表現

量子コンピュータ：

量子状態をそのまま表現

つまり：

```
2^n vs n
```

の差があります。

ここに **本質的優位性** があります。

---

## 11. 量子優位性の種類

量子優位性には複数あります。

代表例：

| 種類     | 内容         |
| ------ | ---------- |
| 理論的優位性 | Shor       |
| 二次高速化  | Grover     |
| 応用候補   | QAOA       |
| 物理的自然性 | 量子シミュレーション |

つまり、**優位性にも段階があります**。

---

## 12. 実用量子計算はどこから始まるのか？

現在の予測では、**最初の実用分野は 量子化学 です**。

次に **材料科学** です。

その次に **最適化問題** です。

最後に **暗号解読** と考えられています。

---

## 13. NISQ時代の限界

現在の量子コンピュータ：

```
NISQ
(Noisy Intermediate-Scale Quantum)
```

特徴：

* ノイズが多い
* qubit数が少ない
* 誤り訂正なし

そのため：

Grover（大規模）

Shor（実用サイズ）

はまだ動きません。

---

## 14. Fault-tolerant量子計算の意味

これまでに扱った **logical qubit** がここで重要になります。

実用量子計算：

```
physical qubit
↓
logical qubit
↓
fault-tolerant QC
```

という構造になります。

つまり：

誤り訂正が完成して初めて

真の量子優位性

が実現します。

---

## 15. 量子コンピュータはNP完全問題を解けるのか？

よくある質問 **巡回セールスマン問題は速くなる？**

答えは **まだ分かっていません**。

現在の理解：

```
BQP ⊄ NP-complete
```

の可能性が高いと考えられています。

つまり、**万能高速化装置ではない** ということです。

---

## 16. 量子計算の本当の強みとは何か？

量子計算の本質は **並列計算ではありません**。

本質は **干渉** です。

つまり：

不要な解を打ち消し
正しい解を強調する

計算モデルです。

---

## 17. 実用量子アルゴリズムの将来像

将来の主役候補：

| 分野   | アルゴリズム |
| ---- | ------ |
| 暗号   | Shor   |
| 探索   | Grover |
| 最適化  | QAOA   |
| 化学   | VQE    |
| 機械学習 | QNN    |

特に **量子化学** が最初の突破口になる可能性が高いです。

---

## まとめ

この章のポイント：

* 量子優位性はすべての問題で成立するわけではない
* BQPは量子計算で解ける問題の集合
* Shorは指数高速化を実現する代表例
* Groverは平方根高速化
* QAOAは有望だが未証明
* 量子化学は最初の実用候補
* NP完全問題への優位性は未解決

ここまでで、**量子計算がどこで強いのか** の全体像が見えてきました。
